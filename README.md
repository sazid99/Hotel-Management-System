# 🏨 Hotel Management System

A web-based **Hotel Management System** built with **C# .NET Core (.NET 9)** using the **Model-View-Controller (MVC)** architectural pattern. This project was developed as a group project for the **CSC-440 (Visual Programming with C# .NET)** course.

---

## 🚀 Features
* **MVC Architecture:** Clean separation of concerns (Models, Views, Controllers).
* **ASP.NET Core Web App:** High-performance, modern web backend using C#.
* **Modular Structure:** Dedicated folders for controllers, views, data models, and static assets.

---

## 🛠️ Tech Stack
* **Language:** C#
* **Framework:** .NET Core (.NET MVC)
* **Frontend:** HTML5, CSS3, JavaScript
* **IDE/Tools:** Visual Studio / Visual Studio Code
